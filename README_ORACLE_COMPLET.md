## 📐 Système Mathématique

### **Comment les Traits Créent un Trigramme**

```
Format : Trait 3 (haut)
         Trait 2 (milieu)
         Trait 1 (bas)

Code Binaire :
  Yang (━━━) = 1
  Yin (━ ━) = 0

Formule :
  Numéro Trigramme = (Trait3 × 4) + (Trait2 × 2) + Trait1
  Résultat : 0 à 7

Exemple :
  Trait 1 : Yin = 0
  Trait 2 : Yang = 1
  Trait 3 : Yang = 1
  
  (1 × 4) + (1 × 2) + 0 = 6
  Trigramme 6 = ☲ Lí (Feu)
```

### **Comment l'Hexagramme se Forme**

```
Trigramme Inférieur (TI) → Ligne dans la Table Périodique
Trigramme Supérieur (TS) → Colonne dans la Table Périodique

Position = GRID[TI][TS]
Résultat = Hexagramme du Yi Ching (1-64)

Exemple :
  TI = 0 (Kūn — Terre)
  TS = 7 (Qiàn — Ciel)
  
  GRID[0][7] = 12
  → Hexagramme 12 = "Adversité"
```

## 📊 Utilisation de la Table Périodique

### **Structure 8×8**

```
          COLONNES (Trigrammes Supérieurs)
          ☷  ☶  ☵  ☴  ☳  ☲  ☱  ☰

    ☷     2 23  8 20 16 35 45 12
    ☶    15 52 39 53 62 56 31 33
LIGNES ☵     7  4 29 59 40 64 47  6
(Tri ☴    46 18 48 57 32 50 28 44
Inf) ☳    24 27  3 42 51 21 17 25
    ☲    36 22 63 37 55 30 49 13
    ☱    19 41 60 61 54 38 58 10
    ☰    11 26  5  9 34 14 43  1
```

### **Utilisation**

```
1. Déterminer l'index du trigramme inférieur (0-7)
2. Déterminer l'index du trigramme supérieur (0-7)
3. Consulter GRID[inférieur][supérieur]
4. Récupérer le numéro d'hexagramme (1-64)
5. Lire l'interprétation de l'hexagramme
```
